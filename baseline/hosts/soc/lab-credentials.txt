Lab defaults from the Wazuh step-by-step install. Not production secrets.
Host binds are 127.0.0.1 only. See the session file harness.yaml.

Dashboard:   https://127.0.0.1:8443     admin / admin
Indexer:     https://127.0.0.1:9200     admin / admin
Manager API: https://127.0.0.1:55000    wazuh-wui / wazuh-wui

The manager API does not use a static API key. Authenticate with
POST /security/user/authenticate and send Authorization: Bearer <jwt>
(default TTL 900s; refresh). Alert search is the indexer (_search on
wazuh-alerts-*), not port 55000.

indexer 9200. Remote harnesses reach those from net-test.
